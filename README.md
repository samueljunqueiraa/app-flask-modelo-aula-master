# 🌐 App Flask Modelo (Aula)

Este repositório contém um modelo de aplicação web desenvolvido com o framework **Flask** (Python), estruturado para fins didáticos e demonstração de conceitos de desenvolvimento back-end.

---

## 🚀 Funcionalidades
* **Rotas Dinâmicas**: Gerenciamento de navegação com Flask.
* **Template Engine**: Uso de Jinja2 para renderização de HTML.
* **Estrutura Modular**: Organização de pastas seguindo boas práticas.

---

## 🛠️ Tecnologias
* **Linguagem**: Python.
* **Framework**: Flask.

---

## 📥 Como Executar
```bash
# Clone o repositório
git clone [https://github.com/samueljunqueiraa/app-flask-modelo-aula-master.git](https://github.com/samueljunqueiraa/app-flask-modelo-aula-master.git)

# Crie um ambiente virtual
python -m venv venv

# Ative o ambiente (Windows)
source venv/Scripts/activate

# Instale as dependências
pip install -r requirements.txt

# Execute a aplicação
flask run
